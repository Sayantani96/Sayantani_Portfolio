# PostHog Release Notes

## August 2026

### 🚀 Introducing Self-Driving Mode

PostHog is expanding its AI capabilities to help teams identify and resolve product issues with less manual investigation.

With the new **Self-Driving Mode**, PostHog can analyze information from across your product, identify potential problems, and help generate fixes.

### What's New

- **Automatic issue detection**  
  PostHog can analyze product signals such as errors, logs, and session recordings to identify potential issues.

- **AI-powered investigation**  
  PostHog AI can use product and customer context to help investigate problems and answer questions about your data.

- **Automated fixes**  
  When a problem is identified, PostHog can generate a proposed code change to help resolve the issue.

- **Pull request generation**  
  PostHog can generate pull requests containing suggested fixes, allowing developers to review changes before merging them.

### Why It Matters

Identifying and diagnosing product issues often requires developers to work across multiple sources of information. Self-Driving Mode brings these signals together so teams can move from **identifying a problem to investigating and fixing it** more efficiently.

### Getting Started

Self-Driving Mode is available through PostHog's AI-powered tooling.

To get started:

1. Sign in to your PostHog account.
2. Open the relevant project.
3. Access the AI or self-driving features.
4. Review the issues and recommendations identified by PostHog.
5. Review any generated code changes or pull requests before applying them.

> **Note:** Review AI-generated changes before merging them into your codebase.

### Availability

Self-Driving Mode is part of PostHog's evolving AI capabilities. Availability and supported functionality may vary by product, integration, and account configuration.
